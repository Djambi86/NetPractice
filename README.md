## Description

This project is a networking training project developed within the 42 curriculum. Its goal is to help students understand and practice fundamental networking concepts through a series of progressive levels and configuration exercises.

The project covers topics such as:
- TCP/IP addressing
- Subnet masks
- Default gateways
- Routers and switches
- OSI layers
- Basic routing and packet forwarding principles

Each level introduces new networking challenges and requires the creation and validation of network configurations.
